Zeamistrap

Bloxstrap をベースにした Roblox 用カスタムブートストラッパーです。 詳細なサーバー情報の表示、FastFlags エディタ、フレームレートキャップの引き上げなど、 Roblox の標準機能にはない便利なツールを Windows 10 / 11 で利用できます。

ダウンロード ソースコード

Zeamistrap を入手できる公式の場所は、この GitHub リポジトリと公式サイトのみです。 それ以外の場所からのダウンロードにはご注意ください。

サポート

バグの報告や機能の要望は GitHub Issues からお願いします。 macOS や Linux をお使いの場合は、 AppleBlox や Sober をお試しください。
